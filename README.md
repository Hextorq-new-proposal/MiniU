# MiniU — Modern React + Vite Platform

Modern React 19 + Vite web platform for MiniU EdTech with dedicated course suites, interactive career matchmaker, verified student outcomes, and Schema.org SEO structure.

## 🚀 Tech Stack
- **React 19** + **Vite**
- **React Router DOM v7**
- **Modular Home Components & Custom Motion System** (`src/styles/homeRedesign.css`)
- **Dynamic SEO & Schema.org JSON-LD Component** (`src/components/common/SEOHead.jsx`)
- **Full Offline-Capable Static Asset Pipeline** (`public/assets/*`, `public/cdn/*`)

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Start local dev server (port 5173)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🌐 Local Development
Dev Server URL: `http://localhost:5173`
